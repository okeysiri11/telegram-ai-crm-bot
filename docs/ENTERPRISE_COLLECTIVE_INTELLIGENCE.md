# Enterprise Collective Intelligence

Sprint **28.8** / Platform Builder **v1.7.0** / Collective Intelligence **1.0**

Architecture where Concierge-orchestrated AI Specialists form a collective intelligence layer — the foundation for the future AI Operations Center and AI City.

## Principles

- One coordinated organization, not isolated agents
- Concierge orchestrates, delegates, combines, and delivers
- Shared knowledge board builds shared conclusions
- Decisions expose alternatives, risks, and business impact
- Every object exposes logical state + visual IDs for future visualization

## Surfaces

| Surface | Capability |
| --- | --- |
| AI Team | Named team with goal, priority, specialists, Concierge |
| Collaboration Panel | Live workspace: speaker, task, progress, consensus |
| Decision Engine | Alternatives with pros/cons/risks + recommendation |
| Knowledge Exchange | Share context, reference knowledge, exchange findings |
| Executive Summary | Final report, explanation, action plan |
| Contribution Cards | Specialist contribution and knowledge usage |
| Ops Foundation | AI Team Map · Visual Layer · Visual IDs · Live Org · 2D AI City |
