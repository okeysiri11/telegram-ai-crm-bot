# Bidex Pilot Execution — Sprint 31.3

**Version:** Platform Builder **v1.38.0** · Sprint **31.3** · **Bidex Pilot Execution**

## Mission

Bidex (Crypto) is the **sixth operational Business Ecosystem** on the existing Enterprise AI Platform. No architecture redesign, no duplicated services, no forked AI/auth.

## What shipped

| Surface | Detail |
|---------|--------|
| Live workflow | `/workspace/crypto` — `BidexLiveWorkflowPage` |
| Domain APIs | Existing finance-da/pay/tr/int + legal-cp + crypto-enterprise/rm + ISAM |
| Shared platform | ISAM · RBAC · Workspace · MC · Knowledge · Workflow template · Comms · AI Team · Concierge · OBS · Audit |
| Reuse matrix | Six-ecosystem audit via `computeReusePercentage()` |

Customer → Login → Identity/KYC/AML → Wallet → OTC Deal → Approval → Settlement → Audit → Mission Control → Analytics
