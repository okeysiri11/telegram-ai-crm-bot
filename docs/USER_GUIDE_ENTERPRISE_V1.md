# Enterprise User Guide — Platform v1.0 GA

**Audience:** Owners, executives, and operators of Enterprise Platform v1.0  
**Status:** General Availability overlay (industry vertical guides remain separate)

---

## First day

1. **Sign in** at `/login`
2. Complete **First Entry** (role → company → ready) or skip if invited into an existing org
3. Open **Morning Brief** on `/dashboard?mode=executive`
4. Follow the **Continue** strip for the next recommended screen

## Daily executive loop

| Need | Where |
|------|--------|
| What needs attention | Morning Brief / Dashboard |
| See the company | Enterprise City |
| Live health | Mission Control |
| Ask / decide with AI | AI Concierge (Advisor) |
| Owner decide-now | Control Tower |
| Preferences | Settings |

## AI Advisor language

Suggestions follow: **Observation · Why · Action · Impact · Confidence**.  
Concierge is the primary assistant; AI Team specialists are available when needed.

## Tips

- Use **Demo** in the top nav (`/demo/scenario`) for a guided tour
- Prefer Executive mode on Dashboard for presentations
- City supports RU/UA visual states for regional ops
- If offline: wait for reconnect banner; last snapshot is kept where possible
