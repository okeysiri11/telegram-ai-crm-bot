# Pilot Operations Guide — Sprint 32.2

## Daily loop

1. `/pilot/execute` — re-run six phases
2. `/pilot` — sessions, onboarding, invites, feedback
3. Mission Control — pilot orgs + KPIs + ecosystem health
4. Triage Critical/High feedback (auto-routed to OBS incidents)

## External org path (no developer)

1. `/pilot/onboard` → full onboarding
2. `/pilot/invite` → token URL
3. `/invite/accept` → membership
4. Select ecosystem LiveWorkflow → Run
5. `/platform-builder/ai-team` → AI activation
6. Submit feedback on Pilot Dashboard

## Metrics (automatic)

`pilotMetrics`: sessions, registrations, onboarding success, invites, workflow completion, API/AI timings, errors-by-module, feedback count + OBS dashboards.
