# Media Manager

**Sprint:** 27.9 · Production Center → Media

## Supported kinds

Images · Video · Audio · Documents · Templates · Brand Assets · Fonts · Icons · Animations

## Behavior

Filter · version badge · draft/approved/archived · add asset (client catalog).

## Reuse

- Documents hub for storage destinations  
- Platform Builder Asset Registry for **visual** UI assets (linked, not duplicated)  
- Future: binary versioning API following PB `VersionRegistry` pattern  

## Non-goals (this sprint)

Real blob storage · GPU render thumbnails · CDN publish
