# SPRINT 42.8 — Universal Vertical Workspace Framework

**Mode:** Enterprise UX + Human First + Vertical Navigation + Russian First  
**Date:** 2026-08-06  
**Package:** `src/web/src/vertical-workspace/`

---

## Verdict

Создан **единый шаблон рабочих пространств** для всех вертикалей ADOS. Страницы не копировались — каждая вертикаль наследует одну оболочку, один дашборд и один AI Консьерж; меняются каталог навигации и набор специалистов.

---

## Архитектура

```
Каталог (VERTICAL_WORKSPACES)
        ↓
WorkspaceSwitcher (верхняя панель · рядом с организацией)
        ↓
/vertical/:verticalId[/:sectionId]
        ↓
VerticalWorkspaceShell (боковая навигация)
        ↓
VerticalDashboard (AI-гид · действия · статистика · события · задачи · агенты)
```

| Файл | Назначение |
|------|------------|
| `catalog.ts` | Все вертикали, разделы, агенты, рекомендации (RU) |
| `WorkspaceSwitcher.tsx` | Переключатель «Рабочее пространство» |
| `VerticalWorkspacePage.tsx` | Маршрут + боковое меню |
| `VerticalDashboard.tsx` | Универсальный дашборд |
| `verticalWorkspaceStore.ts` | Активная вертикаль (localStorage) |
| `verticalWorkspace.css` | Сетка оболочки |

Маршруты в `App.tsx`:

- `/vertical/:verticalId`
- `/vertical/:verticalId/:sectionId`

Переключатель добавлен в `TopNavigation` рядом с названием организации.

## Общий шаблон каждой вертикали

1. **Верхний AI-гид** — «Добро пожаловать» · рекомендации · главное действие  
2. **AI Консьерж** — один и тот же во всех вертикалях  
3. **Специалисты** — зависят от вертикали  
4. **Быстрые действия**  
5. **Статистика**  
6. **Последние объекты**  
7. **Уведомления / события**  
8. **Задачи**  
9. **Поиск**  
10. **Собственная боковая навигация**

Где есть живой модуль (`/crm`, `/workspace/auto`, …), в меню есть ссылка «Полный модуль» / deep `href` — без дублирования бизнес-логики.

---

## Architectural decisions

1. **Новый пакет `vertical-workspace`**, а не копирование `*LiveWorkflowPage` — единый UI-контракт поверх существующих SoR.
2. **Каталог как единственный источник правды** для nav / agents / guide — добавление вертикали = запись в `catalog.ts` + маршрут уже универсален.
3. **Консьерж фиксирован** (`id: concierge`, имя «AI Консьерж») — специалисты фильтруются отдельно.
4. **Switcher в TopNavigation** — по требованиям спринта рядом с организацией (org label + select).
