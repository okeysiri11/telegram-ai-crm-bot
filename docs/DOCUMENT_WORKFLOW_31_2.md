# Document Workflow Guide — Sprint 31.2

## Flow

1. Template (`DI /contracts action:template`)
2. Generated contract/NDA (`DI /contracts`)
3. AI draft (`DI /drafting action:draft`)
4. Case document (`CM /documents`)
5. Version history (`CM /documents action:version`)
6. Digital signature (`CM /documents action:sign`)
7. Approval workflow (`CM /tasks action:approval`)
8. Attachments/evidence (`CM /documents action:evidence`)
9. Document timeline via case timeline + dashboards

## Note

DI comparison approvals expect DI document store IDs — pilot uses CM task approvals for matter-document approval packs.
