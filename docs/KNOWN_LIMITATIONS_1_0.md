# Known Limitations — Enterprise Platform v1.0 RC

1. **Policy gates are compositional** — Governance shows Policy → Permission → Approval → Execution; server-side hard enforcement is not a new Policy Engine and remains partial.  
2. **OKR progress is signal-derived** — not a full ERP/Finance closed loop.  
3. **Learning recommendations** — advisory; no closed feedback “apply → measure → retrain” memory store.  
4. **Audit timeline** — composed from autonomy journal / activity / runtime / notifications; not an immutable compliance vault.  
5. **Bundle** — heavy hubs are lazy-loaded; many legacy PB/visual routes remain eager.  
6. **Dual strategy surfaces** — classic Strategy Engine + OKR Intelligence both available.  
7. **Frame builders** (CRM/ERP/…) — frame/beta status.  
8. **Error boundaries** — root-level only.  
9. **Strip chrome** — secondary strips collapsed by default; expand for full ops strip stack.  
10. **Ecosystem pilots** — vertical maturity varies; see historical production status docs.
