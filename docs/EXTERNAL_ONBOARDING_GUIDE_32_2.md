# External Onboarding Guide — Sprint 32.2

Self-serve path for Beauty, Cafe, Automotive, Legal, Agriculture, Bidex, and Drone organizations.

1. Open `/pilot/onboard`
2. Enter company name + industry + license tier
3. Run full onboarding (tenancy + EON + go-live + EPR first-launch)
4. Open the matching `/workspace/{eco}` LiveWorkflow
5. Invite teammates via `/pilot/invite`
6. Confirm phase **Pilot** passes on `/pilot/execute`

No developer intervention required when APIs are healthy.
